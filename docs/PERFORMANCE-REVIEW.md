# 🎹 Производительность Piano Room

Дата: 15 ноября 2026. Сравнение с `a8dab34`. MacBook Pro, Apple Silicon, macOS 27.2.1.

## Измеренный результат

Пять попеременных запусков исходного и нового оптимизированного DSP-теста без конкурирующих сборок. В таблице медианы; p99 — время, быстрее которого обработаны 99% блоков.

| Показатель | До | После | Изменение |
|---|---:|---:|---:|
| Загрузка Osiris | 5,83032 с | 3,15468 с | −45,9% |
| Загрузка Headroom | 1,79594 с | 0,953773 с | −46,9% |
| Пиковая физическая память отдельного DSP-процесса | 5,537 ГБ | 2,782 ГБ | −49,8% |
| Osiris, p99 расчёта 256 кадров | 98,167 мкс | 82,375 мкс | −16,1% |
| Headroom, p99 расчёта 256 кадров | 48,209 мкс | 48,375 мкс | в пределах шума |

Память измерена через `peak memory footprint` из `/usr/bin/time -l`, а не нестабильный RSS при сжатии памяти. Это отдельный проигрыватель: значения не означают полный расход приложения. Загрузка здесь включает разбор SFZ и распаковку, без подготовки аудиоустройства. Время до первой слышимой ноты и полный путь от физической клавиши до динамиков не измерены.

## Что изменено

- [x] Исходные 16-битные записи хранятся в int16 вместо float32; 24-битные сохраняют прежний путь. Правила нормализации WAV и FLAC сохранены отдельно.
- [x] Порционное чтение по 16.384 кадра; максимум два параллельных декодирования. Заголовки открываются последовательно из-за общего состояния dr_flac.
- [x] Постоянная экспонента формы отпускания вынесена из цикла звуковых отсчётов.
- [x] Старт сразу с выбранным инструментом; GM и SFZ обходятся без предварительного Salamander. Ненужный SF2-сэмплер заменяется при остановленном движке.
- [x] Повторный выбор готового инструмента не сбрасывает ноты и не перезапускает звук.
- [x] MIDI обрабатывается в аудиоочереди; MainActor получает сгруппированные уведомления. Поколения подключения, выбора и остановки отсекают устаревшие команды.
- [x] Старые уведомления MIDI-эффектов не перетирают новые ручные настройки; отпускания нот сохраняются.

Буфер по умолчанию остаётся 128 кадров. Новых зависимостей и дискового кэша нет. Приложение в /Applications не заменено.

## Воспроизводимые проверки

Из корня проекта:

```sh
bash Tools/run-tests.sh
xcodebuild -quiet -project PianoRoom.xcodeproj -scheme PianoRoom -configuration Debug -destination 'platform=macOS,arch=arm64' -derivedDataPath build test
xcodebuild -quiet -project PianoRoom.xcodeproj -scheme PianoRoom -configuration Release -destination 'platform=macOS,arch=arm64' -derivedDataPath build build
```

Повторение измерений после сборки тестового проигрывателя:

```sh
clang++ -std=c++17 -O2 Tools/piano_dsp_test.cpp Sources/Audio/PianoDSP.cpp ThirdParty/SFZPlayer/WAVReader.cpp ThirdParty/SFZPlayer/SampleBuffer.cpp -o build/piano_dsp_test
/usr/bin/time -l build/piano_dsp_test Resources/Instruments/Osiris/Instrument.sfz Resources/Instruments/Headroom/Instrument.sfz
```

Провести пять прогонов каждой версии попеременно, без сборок и других тяжёлых задач. Сравнивать медианы. Тест ограничивает p99 реальным временем блока: 256 / 48.000 = 5.333,3 мкс; во время расчёта новые выделения памяти запрещены.

Точное сравнение звука, шесть сочетаний педали и громкости, аккорды, отпускание и снятие педали:

```sh
clang++ -std=c++17 -O2 Tools/piano_waveform.cpp Sources/Audio/PianoDSP.cpp ThirdParty/SFZPlayer/WAVReader.cpp ThirdParty/SFZPlayer/SampleBuffer.cpp -o build/piano_waveform
build/piano_waveform Resources/Instruments/Osiris/Instrument.sfz | shasum -a 256
build/piano_waveform Resources/Instruments/Headroom/Instrument.sfz | shasum -a 256
```

На этом Mac обе версии дали побитно одинаковые 2.457.600 байт для каждой библиотеки:

- Osiris: `1f4f6d2eb48f96a78e5b0f90689b2ba737f676d34640e93eacdbed5cf58d9005`.
- Headroom: `62a3e7be8ee2346e2b50f1a6e7d2a597715453ce67999125b4fe9f7017136a0f`.

На другой архитектуре возможны отличия округления, поэтому перед изменением следует снять новый эталон прежней версией. ASan и UBSan прошли на синтетических WAV/SFZ-сценариях без диагностик.

## Проверка приложения

- Шесть групп `Tools/run-tests.sh` прошли, включая реальный виртуальный CoreMIDI-вход.
- Полный Xcode Debug прогон: 19 тестов, 0 ошибок (22 исполнения с параметрами).
- После последнего исправления раннего выбора повторно прошли все 9 тестов AppState (12 исполнений с параметрами), включая latestSelectionWinsDuringSavedLibraryStartup.
- Release-сборка прошла.
- Запущенная Release-копия обработала 947 аккордов за 120 секунд с педалью и Program Change. После завершения источника экран очистился, процесс продолжил работу.
- В окне приложения проверены переходы GM → Salamander → Osiris → Headroom → Fuchs → Salamander; каждый выбор завершился готовым инструментом без сообщения об ошибке. Проверено штатное завершение.
- Проверка на слух не проводилась. Само отсутствие аварии не считается доказательством отсутствия звуковых пропусков.

## Ревью и ограничения

Независимое ревью нашло два подтверждённых риска новой MIDI-доставки: восстановление готовности после остановки и запоздавшее отражение эффектов. Оба исправлены. Повторное ревью выявило ранний выбор до создания звуковых модулей; до готовности подготовки сохраняется последний выбор, затем он применяется. Дополнительно полный тест выявил пропавший индикатор сохранённой библиотеки при старте; индикатор и защита последнего выбора восстановлены.

Сравнение полной нагрузки приложения во время двухминутной игры не используется как доказательство ускорения: одновременно выполнялись проверки, а сценарии переключения отличались. Физическое пианино не подключено; динамики пианино и субъективная задержка игры требуют отдельной проверки с оборудованием.

Измерения повторять после изменений загрузчика, обработки нот, эффектов, аудиографа или библиотек. Для отката возвращать связанные изменения MIDI-маршрутизатора и AppState вместе.
