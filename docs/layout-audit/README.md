# Пространственная композиция Piano Room

Проверка и изменения от 14 ноября 2026 года. Работа ограничена интерфейсом SwiftUI; существующие незакоммиченные изменения проекта приняты за исходное состояние.

## Что обнаружено и исправлено

| Наблюдение | Изменение | Композиционный смысл |
|---|---|---|
| Интервалы 5, 7, 13, 14, 18 и 22 использовались для одинаковых отношений | Общие роли расстояний в `Theme.Space`: 4, 8, 12, 16, 24, 32 | Подпись ближе к своему элементу, чем соседняя группа |
| Панель инструментов теснее панели эффектов, центральная сцена получает весь избыток ширины | Ширины 280/288, промежутки 16, поля 16 в узком окне и 24 в широком, предел общей ширины 1568 | Стабильные боковые инструменты и ограниченное растяжение сцены |
| Заголовок сцены расположен ниже заголовков боковых панелей | Общая высота заголовков 24 и внутреннее поле 16 | Общая горизонталь верхнего ряда |
| Небольшая высота окна сжимает вертикальные группы | Отдельная прокрутка списков и эффектов; громкость и каталог за пределами прокрутки | Важные действия сохраняют постоянное место |
| Название, ноты и подсказка образуют одну группу без ясного деления | Название и подпись объединены, ноты отделены интервалом, подсказка закреплена внизу сцены | Главный инструмент остаётся центром внимания |
| Исчезновение подсказки при игре меняет высоту центрального блока | Место нижней подсказки сохранено, скрытая кнопка исключена из взаимодействия и доступности | Сцена сохраняет положение при смене состояния нот |
| Жёсткая строка метаданных сцены и шапки может не помещаться | `ViewThatFits` с вертикальным запасным расположением; длинное имя выхода ограничено | Уменьшение ширины не сталкивает соседние группы |
| Категории каталога разной длины оставляют разрозненные пустоты и выходят за ячейки | Три одинаковые колонки и одинаковая ширина элементов фильтра | Категории читаются как единая область фильтрации |
| Разная ширина секций настроек и несовпадающие правые края полей | Общая ширина секций и правое выравнивание всех списков | Настройки читаются по двум устойчивым вертикалям |

## Система расстояний

- 4: название и подпись, соседние строки списка, компактные метаданные.
- 8: элементы одного управления, ползунок и название эффекта.
- 12: иконка и текст, внутренние поля компактных кнопок.
- 16: содержимое панели, отдельные эффекты, промежутки основной сетки.
- 24: поля большого окна и разделение секций настроек.
- 32: зарезервированная строка нот.

Высота клавиатуры зависит от высоты окна и ограничена диапазоном 160–208. Минимальный размер основного окна сохранён: 1080 × 760. Палитра, шрифты, скругления и устройство звука сохранены.

## Проверка

- Открыто настоящее приложение из `build/Build/Products/Release/Piano Room.app`.
- Первая итерация визуально проверена в окне 1080 × 792 и при разворачивании до ширины экрана. После правки заголовков и каталога итоговый главный экран проверен при 1512 × 852. Повторный точный размер окна через инструмент управления установить не удалось; проверка именно 1080 × 760 остаётся ограничением.
- Итоговый каталог проверен при 760 × 640. Поиск «Орган» вернул четыре инструмента, выбор органа закрыл каталог и обновил сцену.
- Настройки проверены при размере содержимого 520 × 600: все три секции одной ширины, списки выровнены справа.
- Release build: успешно.
- Debug tests на macOS arm64: пять тестов AppStateTests прошли, включая параметризованную проверку четырёх значений буфера.
- Первоначальный запуск тестов в Release остановился на недоступности модуля для `@testable import`; повтор в Debug прошёл. Настройки тестов проекта не менялись.
- `git diff --check`: без ошибок.
- Физическое пианино не подключено; реальный USB/MIDI-сценарий и качество звука в этой работе не проверялись.
