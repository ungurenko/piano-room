# Встроенная реверберация

Реализован согласованный вариант: самостоятельный Signalsmith-реверб с шестью пространствами и раскрывающейся тонкой настройкой. Алгоритм заменяет Apple largeHall2 в прежней цепочке после дилея. Старые значения силы/включения и MIDI CC91 сохранены.

## Управление

Пространства: Комната, Камерный зал (начальное), Концертный зал, Тёплый, Воздушный, Эмбиент. «Настроить» раскрывает хвост 0,3–20 с, размер, паузу 0–100 мс, тембр, ширину и движение. Смена пространства сохраняет силу и включение. Индивидуальные значения сохраняются между запусками.

## Устройство

ReverbUnit связывает AVAudioEngine с C++ через C-интерфейс. Параметры передаются атомарным снимком с номером версии; звуковой поток делает одну попытку чтения и использует предыдущий снимок при незавершённой записи. Память выделяется перед запуском обработки. Команда сброса передаётся атомарным флагом и применяется в начале обработки блока.

Задержки меняются плавно за 100 мс, новые цели заменяют ожидающую цель. Непрерывные параметры сглаживаются с постоянной времени около 30 мс. Предзадержка и ширина воздействуют только на отражения. При выключении прекращается подача новых нот в хвост, исходный звук плавно возвращается к полной громкости.

## Проверки

`bash Tools/run-tests.sh` запускает общие проверки и офлайн-проверки реверба. `bash Tools/run-reverb-tests.sh --demo` дополнительно создаёт сравнения Salamander в `output/reverb-demo/`: без эффекта, прежний Apple largeHall2 и новый Камерный зал. Во всех файлах используется одно исходное исполнение, громкость выровнена по RMS.

Проверяются частоты 44,1/48/96 кГц, блоки 64/128/256/512 кадров, затухание, стерео, выключение, нулевая сила, сброс, повторное выделение ресурсов, выходные буферы без указателей и отказ при превышении допустимого блока. Тесты настроек запускаются через Xcode test и покрывают старые настройки, сохранение, сброс и неверные значения.

Независимый просмотр звукового кода нашёл один дефект: обычный AU.reset оставлял хвост. Дефект подтверждён отдельным падающим тестом, исправлен атомарным запросом сброса; тест проходит. Проверка C++ с AddressSanitizer и UndefinedBehaviorSanitizer прошла.

## Ограничения оценки

Проверки чисел и быстродействия подтверждают техническую работу эффекта. Художественное сравнение с Arturia требует прослушивания. Физическое Grace CP-250 во время разработки не подключено, поэтому его динамики и USB-переподключение не проверены.

Версии, изменения исходного алгоритма и лицензии находятся в ThirdParty/SignalsmithReverb. Лицензии также включены в ресурсы приложения.

## Проверка 14 ноября 2026

Release для arm64 и x86_64, общий run-tests.sh и Xcode test прошли после исправления сброса. Лицензии входят в ресурсы приложения. Три WAV по 12 секунд используют одно исполнение и выровненную громкость; перегрузки нет.

В работающем приложении проверены пресеты, изменение тембра, пометка изменения, раскрытие панели, включение эффекта, повторный выбор динамиков и смена буфера 128/256/128 во время MIDI-игры. После смены буфера движок готов.

Десятиминутная виртуальная MIDI-игра завершилась: 4.717 аккордов, педаль и изменение силы реверба через CC91. Приложение продолжало работать; отсутствие слышимых щелчков человеком не оценивалось. Обновлённая сборка установлена в /Applications/Piano Room.app, совпадение исполняемого файла проверено. После установки программа запущена, возвращены рояль и прежняя сила/выключенное положение реверба.
