# Кандидаты для качественной коллекции Piano Room

Проверка источников: 14 ноября 2026 года. Это исследование; библиотеки не установлены и их звучание в Piano Room не оценивалось.

## Направление

Добавить несколько выразительных инструментов с записями настоящих инструментов, сохранив Salamander как основной рояль. Качество выбирать по одинаковым музыкальным фрагментам, тихим и сильным нажатиям и поведению педали. Число файлов и размер библиотеки сами по себе не доказывают качество.

## Сильные кандидаты

- **Osiris Piano** — тихое фортепиано Karoryfer/Versilian, более 1.200 записей, несколько микрофонных позиций, около 460 МБ FLAC. CC0. Авторские демо: https://shop.karoryfer.com/pages/free-osiris-piano. Хороший кандидат на отдельный спокойный характер рядом с Salamander. Оригинальный инструмент требует Sforzando; совместимость его расширений с другим движком нужно проверять.
- **Greg Sullivan E-Pianos** — Yamaha CP80, Wurlitzer EP200 и Hohner Pianet T. SFZ-пакет: https://github.com/sfzinstruments/GregSullivan.E-Pianos. Пакет объявляет CC BY 3.0; актуальные условия исходных записей на авторском сайте могут отличаться по версии CC BY. При внедрении фиксировать выбранную версию и сохранять атрибуцию. Кандидаты на электропиано; записи старые, выразительность надо оценить прослушиванием.
- **VSCO 2 Community Edition** — камерный оркестр, включая струнные, духовые и ударные, разные приёмы исполнения. CC0. Официальная страница с демо: https://versilian-studios.com/vsco-community/. GitHub: https://github.com/sgossner/VSCO-2-CE. Библиотека около 3 ГБ; для Piano Room можно отобрать отдельные инструменты. Не обещать уровень дорогих коммерческих оркестров.
- **VCSL** — концертная арфа, вибрафон, маримба, клавесины, рояли Kawai и Steinway B, духовые и необычные инструменты. CC0. https://versilian-studios.com/vcsl/ и https://github.com/sgossner/VCSL. Авторы прямо разрешают включение в коммерческое программное обеспечение. Обычно меньше динамических слоёв и вариантов повторной ноты, чем у крупных профессиональных библиотек.
- **Karoryfer x bigcat cello** — близкая запись виолончели, протяжные, короткие и щипковые ноты, 479 записей, загрузка около 126 МБ. https://shop.karoryfer.com/pages/free-karoryfer-x-bigcat-cello. Общая актуальная лицензия бесплатных библиотек Karoryfer — CC0: https://shop.karoryfer.com/pages/free-samples (исключение Marie Ork). Не путать с более подробной коммерческой Vengeful Cello.
- **Emilyguitar** — электрогитара, четыре слоя силы нажатия и три варианта повторной ноты, отдельные звуки отпускания. CC0 в LICENSE. https://github.com/sfzinstruments/karoryfer.emilyguitar. Нужна музыкальная настройка игры с клавиатуры; сэмплы сами по себе не моделируют гитарную технику.
- **FreePats FM Synthesized Piano** — записи синтезированного DX7-подобного электропиано, CC0, есть SF2, который соответствует нынешнему способу загрузки Piano Room. https://freepats.zenvoid.org/ElectricPiano/synthesized-piano.html. Компактный кандидат, художественную ценность сравнить с нынешним GM.

## Дополнительные клавишные после проверки первоисточников

- **Headroom Piano** — Yamaha C3, 300 записей, 5 слоёв силы нажатия, близкие микрофоны и Decca Tree. Исходные WAV около 875 МБ, FLAC-пакет около 156 МБ. SFZ v2 с расширениями ARIA; README предупреждает о необходимости совместимого проигрывателя. Лицензия CC BY 4.0, требуется сохранять исходное название инструмента. https://github.com/sfzinstruments/BengtNilsson.HeadroomPiano. Демо: https://sfzinstruments.github.io/pianos/headroom_piano/.
- **Fuchs & Möhr Felt Piano** — домашнее пианино с мягким характером и небольшой расстройкой. Автор Tom Guder прямо объявляет SF2 и исходные stereo WAV public domain; WAV имеют три динамических слоя, 16 бит. Размер не подтверждён первоисточником. Авторский пост: https://www.polyphone.io/en/forum/your-creations/850-acoustic-felt-piano-upright-fuchs-mohr. SF2: https://www.polyphone.io/en/soundfonts/pianos/683-fuchs-mohr-felt-piano. Совпадает с нынешним форматом загрузки приложения; расстройку надо оценить на слух, а не считать автоматически достоинством.

Greg Sullivan: актуальный авторский сайт https://www.sullivang.net/ объявляет CC BY 4.0 для оригиналов с 21 октября 2026 года. SFZ-переиздание по-прежнему объявляет CC BY 3.0. У CP80/Wurlitzer автор указывает четыре динамических слоя; у Pianet — два и звуки отпускания. Это разные выпуски: при внедрении сохранять документы выбранного выпуска.

## Свои инструменты

Реально сделать авторские сочетания разрешённых записей: рояль со струнными, рояль с тихим воздушным пэдом, электропиано с тремоло и обработкой. Свой акустический рояль с нуля потребовал бы качественной записи реального инструмента либо отдельной разработки физической модели; короткий алгоритм не заменяет эту работу.

Для собственных синтезаторов есть MIT-код MDA EPiano, DX10 и JX10: https://github.com/hollance/mda-plugins-juce. Проверены LICENSE.txt и исходники EPiano/DX10. JUCE лицензируется отдельно: встраивать весь плагин по одной лицензии MDA нельзя. Это возможная основа компактного синтеза, не доказательство современного студийного качества.

## Подключение к приложению

Сейчас приложение загружает Salamander через Apple AUSampler из SF2. Большая часть найденных библиотек использует SFZ — записи с текстовым описанием зон, силы нажатия, отпускания, повторов и других деталей. Форматы SFZ и SF2 не взаимозаменяемы. Простая конвертация может потерять выразительность.

Кандидат на полноценное воспроизведение SFZ — sfizz: https://github.com/sfztools/sfizz, основной код BSD-2-Clause, C/C++ API, macOS. README перечисляет отдельные лицензии зависимостей, включая отличающиеся от MIT/Apache/BSD; состав сборки требует отдельной проверки до внедрения по правилам проекта. Альтернатива для изучения — отделённый SFZPlayer из https://github.com/stevefolta/sfzq; поддерживает более узкий набор SFZ-команд.

## Отсев

Piano in 162 и Hammersmith Free доступны для создания музыки, но условия не дают свободно включить записи в наш собственный распространяемый набор. Pianobook требует проверки каждой конкретной библиотеки. Virtual Playing Orchestra смешивает записи с разными лицензиями и сложнее для распространения, чем чистые CC0 VSCO/VCSL.

## Рекомендуемый первый отбор

Прослушать Osiris, Headroom, Wurlitzer/CP80, камерные струнные и арфу; оставить понравившиеся. Авторские многослойные тембры делать на отобранной основе после проверки качества игры. Не загружать целый оркестр в оперативную память: инструменты подгружать по выбору.
